# Киоск оплаты

## Project Overview
Киоск оплаты - это веб-приложение, позволяющее пользователям вводить номер телефона для выполнения платежей. Оно включает виртуальную клавиатуру для удобного ввода и выпадающий список, который отображает список клиентов, найденных по введенному номеру телефона. Приложение ориентировано на использование в сфере обслуживания клиентов, позволяя быстро находить информацию о клиентах на основе их телефонных номеров.

## Installation
Чтобы запустить проект на локальной машине, выполните следующие шаги:

1. Скачайте или клонируйте репозиторий:
   ```bash
   git clone https://github.com/yourusername/kiosk-payment.git
   ```
   
2. Перейдите в директорию проекта:
   ```bash
   cd kiosk-payment
   ```

3. Откройте файл `index.html` в веб-браузере.

## Usage
1. Введите номер телефона с помощью виртуальной клавиатуры.
2. При вводе номера телефона будет отображен список клиентов, соответствующий введенному номеру.
3. Выберите клиента из выпадающего списка, чтобы заполнить поле ввода.
4. После выбора необходимого клиента нажмите кнопку "Оплатить", чтобы обработать платеж.

## Features
- Виртуальная клавиатура для удобного ввода номера телефона.
- Выпадающий список клиентов, который обновляется в реальном времени по мере ввода.
- Валидация номера телефона перед обработкой платежа.
- Поддержка сохранения последнего введенного номера телефона в `localStorage`.

## Dependencies
